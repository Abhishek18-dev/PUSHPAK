# DOWNLOAD PLAN

No downloads are authorized during local development.

For every future external dependency/artifact, record:

- Item
- Why required
- Source
- Version
- Approximate size
- Destination inside project
- Verification/checksum
- Whether required for MVP/V1/V2
- Intended cloud/Codespace installation command
- Whether it can be replaced by an existing approved dependency

Nothing listed here should be downloaded automatically.
